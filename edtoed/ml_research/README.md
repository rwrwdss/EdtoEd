# Обучение модели

Пайплайн обучения пока не реализован. Он должен читать размеченные события из PostgreSQL, воспроизводить порядок признаков из `internal/features` (`relative_clicks`, `test_score`, `deadline_delay`) и экспортировать ONNX с входом `float_input` формы `[N, 3]`. Текущий артефакт возвращает `label` и `probabilities` типа `sequence<map<int64,float>>`.

Для переобучения нужны подтверждённые метки оттока. Поле `is_trained` в таблице отмечает обработку события, но не заменяет целевую метку. До появления меток обучение на логах запускать нельзя.
