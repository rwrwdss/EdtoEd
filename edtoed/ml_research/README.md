# Обучение модели

Актуальная модель согласована с API: медиана по всей доступной когорте, включая нули, минимум два студента, положительная медиана. Задержка сохраняет знак; clipping отсутствует. При отсутствии оценки и задержки используются нули.

Train: 2013; validation: 2014B; test: 2014J, без повторных студентов между выборками. Учитываются только зарегистрированные и ещё не ушедшие к дню 28 студенты. Сдачи после дня 28 и зачтённые ранее работы исключены. Клики агрегируются за дни 0–28 включительно: эквивалент окна API [начало дня 0, начало дня 29).

На 7 929 зачислениях из 2014J калиброванная модель при пороге 0.434 показала ROC-AUC 0.694, F1 0.578, precision 0.502 и recall 0.681. [Отчёт](artifacts/oulad_baseline_report.md) содержит сравнение с прежней моделью при пороге 0.7, параметры калибровки и эталонные прогнозы. OULAD уже использовался в разработке, поэтому для оценки переноса нужна независимая выборка.

Запуск из этой папки:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 train_oulad.py
python3 -m unittest test_training -v
```

Зависимости: numpy, pandas, onnx, onnxruntime (версии закреплены в CI). Данные ожидаются в data/raw/oulad или data/raw/oulad.zip. Скрипт создаёт кандидата в artifacts и сравнивает с текущим ../models/edtoed_v1.onnx; production-файл автоматически не заменяется. Для promotion нужны validation gate, оценка компромиссов и обновление эталонов Go.

Текущий кандидат продвинут в models после проверки; там один ONNX-файл. Старые версии доступны в Git. Сырые данные игнорируются. is_trained не является меткой исхода.

Калибровка Платта встроена в ONNX как аффинное преобразование логита. Файл модели и порог в Go должны обновляться вместе; тесты ONNX сверяют эталонные прогнозы. Полный JSON-отчёт содержит калибровку, разбиение и сравнение со старым порогом.
